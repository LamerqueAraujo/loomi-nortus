# Loomi Nortus – Case Técnico

Este repositório contém a implementação do desafio, com foco em organização, clareza e boas práticas.

## Visão Geral

O projeto foi iniciado na branch **develop**, conforme solicitado no desafio. A estrutura foi planejada para ser simples, objetiva e fácil de manter.

## Estrutura do Projeto

```
src/
 ┣ components/
 ┣ pages ou app/
 ┣ services/
 ┣ utils/
 ┗ config files
```

## Tecnologias

* Next.js / React
* TypeScript
* TailwindCSS
* ESLint + Prettier

## Fluxo de Git

* main → versão final
* develop → base do desenvolvimento
* feature/* → funcionalidades específicas

Padrão de commits (português):

```
feat: descrição
fix: descrição
docs: descrição
chore: descrição
```

## Como Rodar

### Ambiente de Desenvolvimento

```
npm install
npm run dev
```

### Ambiente de Produção

```
npm install
npm run build
npm start
```

```
yarn install
yarn dev
```

## Objetivo da Entrega

Demonstrar domínio de organização, versionamento e estruturação de um projeto escalável.
